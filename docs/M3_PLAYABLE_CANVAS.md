# M3 円表示で遊べるブラウザ版

この文書は、M2の決定的ゲーム判定をブラウザへ接続するM3の実装記録です。仮の円表示でも、ホームから60秒のプレイ、最終連鎖、結果、入力再生確認まで進めることを目的とします。

## 実装境界

| 層 | 責務 |
|---|---|
| `src/game/session.js` | 1tickにつき1入力をM2へ渡し、3600フレーム、最終連鎖、結果、厳格な再生照合を管理する |
| `src/game/controller.js` | 画面状態、固定tickの蓄積、表示更新、非表示・回転時の時計停止と再開を管理する |
| `src/input/pointer-controller.js` | 最初のPointer、Pointer Capture、CSS座標から整数盤面への変換、中断入力を管理する |
| `src/render/` | M2の状態を仮の円、爆発、連鎖、指と照準の線として描画する。判定状態は変更しない |
| `src/ui/` | ホーム、カウントダウン、プレイ、最終連鎖、結果、HUD、縦画面案内を表示する |

公開ページはビルド工程や外部実行時依存を追加せず、既存の静的サーバーから配信できます。

## 固定tickと入力再生

- `requestAnimationFrame`は表示の予定だけに使い、ゲーム判定は60Hzの蓄積時間から独立して進める。
- 1回の描画で処理する固定tickは最大12に制限する。通常の遅れは次の描画へ持ち越し、1秒を超えるbacklogは一回の明示的な中断入力として再同期して追いつき暴走を防ぐ。
- 複数tickを処理した場合も状態差分イベントは各tickで消費してSEを落とさず、Canvas/HUDはバッチ後に1回だけ描画する。pointermoveは最新座標だけを更新し、別の即時描画経路を作らない。
- 各tickでPointerの最新位置を一回だけ取得し、イベント発生回数を得点や判定へ混入させない。
- CSSの`getBoundingClientRect()`から16000×9000の整数盤面へ丸めて制限する。Canvasのbacking storeやDPRは入力へ影響しない。
- 指の表示位置と判定に使う端対応の照準位置を分け、判定と画面上の照準を一致させる。
- 3600フレーム後は新しい入力を拒否し、最終連鎖を解決して結果へ一回だけ遷移する。
- seed、ルール指紋、全3600入力を保存し、同じ最終状態・得点になることを厳格に照合する。

## Pointerとライフサイクル

- 最初に押されたPointerだけが操作を所有し、二本目以降は移動も解除もできない。
- `pointercancel`は取消、capture喪失・非表示・ページ遷移・回転は一回だけの中断フレームとして記録する。
- 非表示中と縦画面中は固定tickを進めず、復帰時に経過時間の追いつき処理を行わない。
- capture喪失だけではゲーム時計を止めず、操作だけを解除する。
- Pointer CaptureはAPI呼び出し後の所有状態を確認し、無言のno-opや不正な終了イベントでは操作を強制解除する。
- 最終連鎖中に非表示になった場合も、復帰後に結果遷移を再開する。
- Canvasとゲーム領域ではスクロール、選択、長押しメニューを抑止する。

## 自動検査

- Node契約試験: 座標変換、DPR非依存、最初のPointer、二本目無視、取消、中断、capture取得失敗、3600固定フレーム、終端入力拒否、結果一回、厳格な再生一致。
- Chromium試験: 667×375、844×390、1024×768、375×667、マウス選択、二本目無視、取消、回転、画面端照準、60秒境界、最終連鎖の中断復帰、結果一回、別viewportでの再生一致。
- M2の全量シミュレーションと厳格な再生成果物は既存CIで継続検査する。

ローカル実行環境にChromium本体がない場合、ブラウザ試験はGitHub Actionsで確認します。

## M3で残す確認

- iPhone 17 Pro Safariの横画面操作（タップ位置、長押し中の色選択、色選択の取りこぼし）。
- 縦画面では開始せず、横向き案内を表示する。
- iPhone 11 Pro、iPad Pro 2018は今回のMVP実機受入対象外とし、将来の互換性確認候補にする。
- 端末回転、アプリ切替、通知など実機固有の中断から復帰できること。

実機確認が終わるまではM3の端末適合を完了扱いにしません。また、M2の全量比較では6個待ち戦略が首位であり、ゲーム設計の合格条件は未達です。M3では得点式を固定せず、M4で抜け道対策とゲーム設計審査を続けます。
