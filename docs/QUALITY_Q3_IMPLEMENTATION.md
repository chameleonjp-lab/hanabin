# Q3 ルール別の記録を守る

監査 F07/G01/G02 の修正。ランキングと自己ベストを `ruleVersion` 付きの保存領域へ分け、旧 `hanabin:ranking:v1` は読み出して現行ランキングへ混ぜない。明示された旧版の自己ベストだけは同じ旧ルールの保存領域へ一度だけ移し、ルール不明の記録は保持したまま採点比較から除外する。

ランキング上位10件と自己ベストを別に統合する。自己ベストの最高連鎖数は上位10件に入らない低得点のプレイでも失わない。複数タブが異なる順序で保存しても、保存直前に共有値を読み直し、得点・連鎖数が下がらないようにする。保存が拒否された場合は、そのタブの表示を直ちに巻き戻さない。

結果画面の登録条件を `finished`、エラーなし、再生検査成功の三つに限定した。結果を複数回描画しても、同じプレイの識別子を使って一度だけ登録する。別のプレイが同じ seed・得点・操作数になっても、別の識別子で登録できる。

## 検査

`tests/unit/local-ranking.test.mjs` は旧領域の隔離、版別保存、得点と最高連鎖の独立統合、2タブの順不同保存、既知版の一度限りの移行、保存拒否を検査する。`tests/unit/m6-product.test.mjs` は自己ベストの単調更新、異常結果の登録拒否、同じ結果値でもプレイ識別子を分ける契約を検査する。

保存件数の長期的な上限と実機Safariの容量制限は、統合検査およびiPhone受入で確認する。保存が拒否されてもゲームの採点と再生は続ける。
