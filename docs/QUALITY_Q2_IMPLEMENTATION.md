# Q2 練習と連鎖案内の判定を揃える

監査 F04/F05 の修正。練習の失敗・時間切れ・割り込み・段階移行では、次の操作が古い選択を引き継がないように、押下・候補・保持・軌跡・選択を一つの境界で初期化する。成功画面だけは選択した対象のコピーを表示用に残し、表示後に実際の次操作へ持ち越さない。練習は18秒以内の2段階で、最初の同色3個、次に動く同色3個と爆発だけが届く対象を案内する。時間切れは自動成功や自動進行にしない。

連鎖案内とコアの衝突判定は、通常対象・表示中・予約されていない対象だけを伝播対象にする共通判定を使う。ゲームを続けるための `choice-reserve` は直接起爆の点を持つが、連鎖の発生元にも巻き込み先にもならない。HUDの「近くに届く」表示も同じ半径と適格条件を使うため、案内だけが成立する状態を避ける。

## 検査

`tests/unit/q2-practice-guidance.test.mjs` は、失敗後の再入力が独立すること、成功表示用コピーが元の選択を変更しないこと、予約・消滅・範囲外の対象を案内とコアの両方から除外することを検査する。既存の連鎖・選択保証・商品シェル検査も通過している。

練習の成功率や初見プレイヤーの理解度は自動検査からは判断できないため、iPhone Safari と5人の手動受入で確認する。
