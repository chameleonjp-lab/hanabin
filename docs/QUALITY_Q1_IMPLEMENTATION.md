# Q1 入力座標と画面レイアウト

監査 F01〜F03 の修正。タッチ・マウス・ペンの入力を同じ盤面座標へ変換し、表示する照準もその座標へ置く。以前のマウス用上方向補正は廃止したため、表示円と実際の選択位置がずれない。固定 tick、保持3 tick、リンク距離、採点は変更していない。

縦長画面では盤面の高さから幅を計算し、同じ `9:16` の比率を frame と canvas に適用する。安全領域を含む利用可能な高さを使い、縦長の 375×667、393×852、430×932、320×900 を回帰対象へ追加した。一時停止ボタンは44px以上の領域を持ち、HUDとは別の列を予約する。

## 検査

`tests/unit/q1-layout.test.mjs` は共有比率・HUD予約・自然な入力座標を検査する。`tests/unit/m3-input.test.mjs` は3種類のポインターと四隅で照準と指標が一致することを検査する。実ブラウザの複数サイズ検査は `tests/e2e/m3-playable.spec.mjs` に追加し、CI の Playwright Chromium/WebKit Touch で実行する。

実機 iPhone Safari の回転、安全領域、指が表示を隠す場合の見やすさは、ユーザーの実機受入で確認する。
