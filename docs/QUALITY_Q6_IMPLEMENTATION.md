# Q6 初見プレイと終端表示の改善

監査 G04/D02/D03 のうち、コードで確認できる範囲を実装した。音声は無効時に音声コンテキストを作らず、iPhone Safari が `suspended` または `interrupted` を返した間は発音を予約しない。ユーザー操作での復帰処理は同時に一つだけ実行し、復帰に失敗した場合は次の操作で再試行する。音声の種類、音量、同時発音数の上限は既存の設定を保つ。

ゲーム画面の英語だけの技術ラベルを「得点」「残り時間」「連鎖」「選択」「爆発範囲」「選べる数」「次の予告」へ置き換え、Canvas内の `FIXED 60Hz / 16:9` 表示を取り除いた。固定 tick や盤面比率は内部契約として維持する。終了処理の2フレーム表示には、採点を変更しない読み取り専用の現在得点と最大連鎖を表示し、結果画面へ移る見出しへフォーカスを戻す。

端末保存が拒否された場合は、結果画面で保存できなかったことを明示し、その場で結果を確認できるようにした。リタイアや再生検証失敗など記録対象外の結果も、理由を同じ画面に示す。

## 検査

`tests/unit/q6-experience.test.mjs` は、画面文言・技術ラベルの除去、割り込み中の音声未予約、音声復帰の同時実行抑制、発音数上限、終了表示の存在を検査する。既存の音声・結果・描画テストも実行する。

iPhone 17 Pro の画面ロック・通知・アプリ切替からの復帰、音量、音割れ、および初見5人の理解度は実機受入で確認する。得点式や波の時刻は試遊結果がないため変更していない。
