## 1. 今回の判断

「3個以上選べる」だけでは、波が消えた瞬間に選択肢が1個以下となり、ゲームが進行できない。そこで、プレイ中は**同色かつ選択距離内のグループを4個以上**保つ。4個目は通常波の生成数を水増しせず、必要な瞬間だけ決定的な予備候補として補充する。予備候補は予告ボーナスや連鎖の巻き込み対象にはせず、表示上の選択肢不足を埋める用途に限定する。

オンライン公式ランキングは、サーバー再計算と不正対策が未実装のため今回の範囲に含めない。結果画面のランキングは「この端末のランキング TOP10」と明示したローカル記録とする。

## 3. 受入条件

### 自動検証

- 初回プレイ開始後、HUDの`CHOICES`が4以上である。
- 現在の同色グループを消しても、次の固定tickで4個以上へ回復する。
- 予備候補の補充で予告スケジュール、連鎖帰属、得点台帳、再生結果が壊れない。
- 一時停止中に30 tick進めても`actionCount`が変わらず、再開後だけ1境界を消費する。
- リタイア結果は明示され、通常結果のランキングへ追加されない。
- 空の名前では練習・本番開始へ進めず、有効な名前で進める。
- 結果画面にホーム、実験場、端末内TOP10が表示される。11件以上は10件に切り詰める。
- PCのマウス押下→移動→離上で得点が発生し、入力記録が決定的に再生できる。
- 同一tick内のポインター経路に対象が含まれても、3更新保持を満たしたときだけ選択が確定する。押下→移動→離上が1tick内で完了した場合は選択しない。
- Pointer Captureが取得できない環境でもwindowの移動・離上・cancelへフォールバックし、押下状態を残さない。
- 縦画面の盤面比率が9:16で、論理盤面の4隅と入力座標の対応が一致する。
- Node単体、10,000 seed安全検査、Chromium、WebKit Touchを再実行する。
- Pagesワークフローの全Actions参照が40桁のコミットSHAで固定されている。
- 初見導入は、ホームで3つの要点が見え、練習STEP 1で静止した同色3個、STEP 2で動く同色3個と近接対象の巻き込みを体験できる。
- 練習STEP 2は、選択不可の近接対象を表示するだけで成功にせず、現行の直接爆発半径判定を満たしたときだけ成功する。
- 練習は合計18秒（STEP 1が8秒、STEP 2が10秒）で、スキップ、時間切れ、本番の`practiceCompleted`保存を既存契約どおり扱う。
- 押下中に対象を取得できなかった場合、保持不足・距離外・異色・クールダウンなどの短い理由を表示し、離した後まで誤って表示し続けない。
- 結果画面のヒントは既存の得点台帳から平均選択数、選択解除、連鎖比率、予告成功を導出し、次の行動を1文だけ表示する。判定・得点・リプレイ形式は変えない。
- 次の波まで予告条件の時間内に入ると、HUDの予告欄が強調され、選択中は不足する選択数または金色の二重リング数、条件達成時は「予告準備OK」を表示する。予告の判定・得点・リプレイ形式は変えない。
- 直接爆発・第1世代の連鎖・第2世代以降の連鎖は、色、輪の太さ、内側／外側の構成が異なる。5・10・20・30連鎖の節目は到達値に応じて1〜4重のパルスを表示し、低品質でも得点ラベルを1つ表示する。これらは描画だけで、判定・得点・リプレイ形式を変えない。

### 実機・人手検証

自動のWebKit TouchはiPhone 17 Pro Safariの代替証明ではない。次をiPhone 17 Proで確認し、実測値を別の受入記録へ残す。

- 縦画面で開始し、上側が右・下側が左になること。回転中に選択が起爆しないこと。
- 横・縦の両方で、短いタップ、3更新保持、ゆっくりしたなぞり、速いなぞり、画面外離脱を各10回。
- 二本指、ダブルタップ、スワイプ、Safariの長押しメニュー、pointercancel、Pointer Capture喪失。
- 一時停止からの再開・リタイア・ルール説明、名前必須、結果導線、TOP10表示。
- 音・描画品質・安全領域・画面回転・アプリ切替。

現時点では、上記実機検証と初見5名の試遊が未完了であり、MVP受入を7/7へ先行更新しない。
