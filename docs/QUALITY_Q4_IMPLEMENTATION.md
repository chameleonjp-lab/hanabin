# Q4 実在する波だけを予告・採点する

対象: 2026-09-08 Astra 監査 F06。ルール版は `m4-gameplay-4`。

60秒のセッション内で出現する波だけを予告へ渡す。最終波の5個の先読み用対象は位置・色・個数を保って通常対象として残し、存在しない次の波への金色マークを付けない。HUDと起爆時の採点でも同じ時間境界を検査するため、古い予告メタデータが残っても準備完了・予告ボーナスにならない。

コアは最終 tick に出現処理を行ってから終了するため、共通条件は `fireTick <= maxTicks`。現行の最後の波は index 19 / tick 3420、index 20 / tick 3630 は対象外。60秒・波の時刻・入力保持時間・通常得点・連鎖得点は変更しない。最後の波以降も予告利用の自動戦略は盤面上の5個を狙って続行する。これは比較用戦略の修正であり、人の上達の証明として扱わない。

採点結果が変わるため Q3 の版別保存を先に取り込む。旧版記録は新版の自己ベストと比較せず保持する。旧入力を新ルールで再生して一致させる互換処理は行わない。

予告を6個以上で選択した案内は「予告は5個限定・今は通常起爆」とし、個別解除ができない操作へ「5個に調整」と案内しない。
