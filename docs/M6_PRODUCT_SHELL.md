# M6 製品シェル検証

## 範囲

M5を`main`へマージした後の製品導線を対象とする。決定的なゲーム判定、固定tick、入力再生、得点計算は変更せず、初回起動から再挑戦までを製品シェルでつなぐ。

## 実装した導線

- 初回の18秒操作練習。最初は固定配置の同色花火を3つ選び、成功後に動く同色花火3つと近くの巻き込み対象へ進む。練習開始、再挑戦、またはスキップを選べる。
- 練習に成功した場合だけ`practiceCompleted`を保存する。スキップは`practiceSkipped`として別に保存し、時間切れでは本番へ進めない。
- プレイヤー名、演出品質、音の有効・無効を端末内へ保存する。音の初期値は無効。
- 壊れた保存JSON、保存不可環境、範囲外の数値は安全に処理する。保存の読込み／書込みに失敗した後も、同じタブでは直前の練習・音・品質設定をmemory上で維持し、初期値や古い保存値へ巻き戻さない。
- 名前は前後空白を除き、1〜12文字、改行・制御文字を拒否する。結果画面へは`textContent`で表示する。
- 予告計画に成功した起爆はプレイ中に知らせ、結果画面へ予告成功回数を表示する。表示値は既存の`bonusEvents`から導出し、判定コアの得点やリプレイ形式は変更しない。
- 結果画面へ得点内訳、端末内最高得点・最大連鎖、一つだけの次回ヒントを表示する。
- 次回ヒントは内部の更新単位を使わず、「押したまま待つ」「短い待ち時間に準備する」のような操作語で表示する。
- 共有文を作り、公開URLを文末へ置く。Web Share、Clipboard、従来のコピーAPIの順で利用する。
- 非表示、ページ遷移、画面回転から復帰すると、選択解除の割り込みを保持したまま3秒の再開表示を行う。テスト用固定tick橋では時間待ちを省略する。
- 効果音は`SoundController`が担当し、音の状態やAudioContextをゲーム状態・再生ログへ保存しない。

## 2026年9月3日 ゲームクリエイターレビュー追補

初見が本番へ進む前に「3つをつなぐ」と「巻き込む」を短時間で体験できるよう、次を追加した。ゲーム本編のルール版、入力記録、得点計算は変更していない。

- ホームの中心説明を、同色3つ・指を離す・近くへ広がるほど高得点の3点へ整理した。細かな制限と得点表は既存の詳細欄へ残した。
- 練習を2段階化した。STEP 1は従来どおり静止した同色3個、STEP 2はゆっくり動く同色3個と、直接爆発半径内の選択不可ターゲットを表示する。STEP 2は実際の半径判定を満たしたときだけ成功する。
- 練習の時間表示は合計18秒（8秒＋10秒）とし、成功・スキップ・時間切れの保存契約は従来どおり維持する。

初見5人、iPhone 17 Pro Safari、音ON/OFF、縦画面での人手受入は未確認である。今回の自動試験は練習の段階遷移と幾何判定を対象にし、人間の理解度を合格扱いにはしない。

## 2026年8月23日 作業ブランチ追補

`agent/mobile-desktop-experience-20260823`では、ホームから何度でも操作練習へ入り、再挑戦・本番・ホームを選べる導線、得点と爆発範囲の説明、自動品質の実効値表示、結果の加点内訳と減点0表示を追加した。効果音はtap、trace、select、chain、detonate、spawn、expire、score、cancelと連鎖節目を鳴らす。tapは受理したDOM押下だけ、それ以外は状態差分を発火源として重複を防ぐ。音は引き続き初期OFFで、iOS / WebKit向けにユーザー操作からAudioContextの作成・再開を試す。

この追補と同じブランチに全端末共通のバランス更新もあるため、M6当時の「得点計算は変更しない」とは工程を分けて記録する。入力・描画・製品導線の関連単体試験54件はローカルで成功し、その後Pull Request [#34](https://github.com/chameleonjp-lab/hanabin/pull/34)で`main`へマージされた。追加要件はPull Request [#36](https://github.com/chameleonjp-lab/hanabin/pull/36)でマージ済みである。iPhone 17 Pro / Safariでの練習理解度、各効果音、タップ・長押しは**実機未確認**であり、仕様と未確認項目は`docs/EXPERIENCE_BALANCE_AUDIT.md`およびM7チェックリストを参照する。
