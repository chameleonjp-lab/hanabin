## 1. 記録のルール

結果を推測で埋めない。確認していない項目は「未確認」と書く。

同じ確認を複数端末で行う場合も、端末ごとに分けて記録する。個人名、メールアドレス、端末内の個人情報、共有文の全文はこのリポジトリへ記録しない。必要な場合は、確認日、端末種別、ブラウザ、結果だけを残す。

公開URLの自動検査で確認済みの次の範囲は、このチェックリストで再確認済みとは扱わない。

- ホーム → 初回練習 → スキップ → カウントダウン → 本編 → 実時間60秒 → 結果画面
- 結果画面の二重登録がないこと
- JavaScriptエラー、4xx以上の応答、失敗リクエストがないこと
